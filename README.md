# xfollow - 拒绝渣蓝

在**你自己**的 X(Twitter)账号里,找出没回关你的、查出谁取关过你。纯本地运行。

> 这个仓库是给**想先用上的人**用的:扩展还在 Chrome 应用商店审核中,这里放的是可以直接
> 装的构建产物,用开发者模式加载。商店通过之后建议改用商店版本(原因见下面「关于更新」)。

---

## 安装(开发者模式)

1. 下载 [`xfollow-0.6.38.zip`](./xfollow-0.6.38.zip)(或点右上角 **Code ▸ Download ZIP**)。
2. **解压**到一个你不会删的目录里(Chrome 不能直接加载 zip,必须解压后的文件夹)。
3. 打开 `chrome://extensions`。
4. 打开右上角的 **开发者模式**。
5. 点 **加载已解压的扩展程序**,选**解压出来的那个文件夹**(里面直接就是 `manifest.json` 的那一层)。
6. 打开 x.com,点扩展图标 —— 页面右侧会滑出抽屉。

> 装完 Chrome 可能会提示"可能会损害您的浏览器"。这是所有非商店扩展的通用提示。

### ⚠️ 关于更新(一定要看)

**开发者模式装的扩展不会自动更新。** 这个项目改得很勤,旧版本可能带着已知问题却毫无提示。
想拿新版就回到这里重新下一次。嫌麻烦的话,等商店版本上架。

## 它做什么

三个名单,只看**最近一次扫描覆盖到的人**(避免名单冻结在旧数据上):

| 名单 | 收谁 | 扫描谁 |
| --- | --- | --- |
| **回关检测** | 关注了你、是蓝V、你还没回关的人 | 最近 200 个粉丝 |
| **未回关** | 你关注了、但没回关你的人(含后来取关你的) | 最近 200 个关注 |
| **渣蓝** | 曾经关注过你、后来不关注了的人 | 粉丝列表(**扫到底**) |

「渣蓝」这一栏需要把粉丝名单扫到底才能判断"他不在名单里了",所以它比另外两栏慢得多;
扫描不完整时它**不会**给出这个结论。

每行的主按钮上写的就是它做的事(关注 / 取关),点了会在一个**隐藏的后台标签页**里替你点 X 自己的按钮,
你当前浏览的页面不受影响。

---

## 三条边界(代码里就写着,不是口头承诺)

1. **不主动调用 X 的任何接口。** 名单是**被动读取**页面自己发出的请求响应;动作是**点击 X 自己的按钮**,
   请求由 X 的页面发出。扩展自身不构造、不代签任何请求。
2. **一次只做你点的那一个,两次之间至少隔 6 秒。** 批量关注是账号被盯上的典型模式。
3. **失败不重试。** 任何失败都停下来并说明原因,不换种写法再试。

数据不出本机:名单、历史记录、忽略名单都存在浏览器本地存储里,没有服务器、没有统计上报。
